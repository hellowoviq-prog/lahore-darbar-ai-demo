LAHORE DARBAR VOICE DEMO — GITHUB PAGES

BEHAVIOR
- Text customer input -> Botpress text reply only.
- Customer audio/voice input -> Botpress understands it -> bot text reply appears -> same reply is generated by OpenAI TTS and played as voice.
- If browser autoplay is blocked, a Play voice button appears.

DEPLOY
1. Open GitHub repo: lahore-darbar-ai-demo
2. Replace existing index.html with this file.
3. Commit to main.
4. Wait 30–90 seconds for GitHub Pages.
5. Open:
   https://hellowoviq-prog.github.io/lahore-darbar-ai-demo/
